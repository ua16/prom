# prom

A vibe coded tool for prompt templating from the commandline.

This was created to do more one shot prompt stuff directly from vim. The idea is that
you select some text in vim and then run prom on it as an
external command.

## Current features

- Insert existing templates using `/file filename`. 
- Insert the output of shell commands using `!command`.
